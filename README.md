# REA-experient — Deluxe Salon Clone

A full-stack Next.js clone of [deluxsalon.in](https://deluxsalon.in/), reverse-engineered using REA methodology.

## Tech Stack
- **Frontend**: Next.js 16 + React 19 + Tailwind CSS
- **Backend**: Next.js API Routes (chat, visitor counter)
- **Audio**: YouTube IFrame Player API + Web Audio API
- **PWA**: Service Worker + manifest.json

## Getting Started
```bash
npm install
npm run dev
```

## API Routes
- `GET /api/chat/fetch` — Fetch chat messages
- `POST /api/chat/send` — Send a chat message
- `GET /api/visitor` — Get visitor count

## Routes
- `/` — Main 2000s Bollywood radio
- `/bhojpuri` — Bhojpuri Bangers
